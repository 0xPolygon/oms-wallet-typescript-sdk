# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately with the **Report a vulnerability** button in this repository's
[Security tab](https://github.com/0xPolygon/oms-server-wallet-sdk/security). Reports in scope for
Polygon's bug bounty programs can also go through them. See the
[Polygon security policy](https://github.com/0xPolygon/.github/blob/main/SECURITY.md) for channels,
what to include, and response times.

## Supported versions

| Version            | Supported        |
| ------------------ | ---------------- |
| 0.2.x              | ✅ Supported     |
| Earlier than 0.2.0 | ❌ Not supported |

## Scope

This policy covers the `@polygonlabs/oms-server-wallet-sdk` npm package, including its `/trails`
entry point.
